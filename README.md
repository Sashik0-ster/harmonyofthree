## ✨ Про проект

**[Harmony Of Three]** — це веб-застосунок всередині Telegram (Telegram Mini App), створений для людей, які прагнуть віднайти внутрішню гармонію, розвивати усвідомленість та щоденно практикувати самопізнання.

Завдяки інтеграції з Telegram користувачі отримують швидкий доступ до медитацій, щоденних карт-карт та духовних практик без необхідності встановлювати додаткові додатки.

---

## 🌟 Основні можливості

* 🔮 **Карта дня / Духовні підказки:** Щоденне натхнення, афірмації та глибокі запитання для рефлексії.
* 🎧 **Аудіо-медитації:** Короткі та довгі практики для розслаблення, сну та концентрації.
* 📖 **Щоденник вдячності та думок:** Можливість зберігати власні роздуми (з можливістю синхронізації з ботом).
* 🕯 **Трекер практик:** Відстеження щоденного прогресу медитацій та збереження «серій» (streaks).
* 🌌 **Енергетичний календар:** Місячні фази, астрологічні або духовні події дня.

---

## 🛠 Технологічний стек

* **Frontend:**  Vue.js (з підтримкою ` @telegram-apps/sdk`)
* **Стилі:** Tailwind CSS / Telegram UI Components (для збереження нативного вигляду Telegram)
* **Backend:** Laravel 13 (FastAPI / aiogram для бота)
* **База даних:** MySQL
* **Хостинг:** None
